学校作为一所注重国际化人才培养的十二年一贯制学校（小学至高中），致力于以习近平新时代中国特色社会主义思想为指导，坚持正确政治方向，支持中国共产党的领导，拥护中国特色社会主义制度，积极响应国家教育现代化2035规划。
